There has been news, particularly about OpenAI's more advanced AI models like 5.6 sol, but also Anthropic's Claude Fable, about these models starting to be capable enough at long-running tasks that they can make advances such as solving unsolved math problems. I think one of the keys to getting that kind of performance out of a model is giving the model an objective that it can itself test against, so that it continues working until that objective is met and it's able to test along the way. I am very interested in exploring these kinds of novel, next-level uses of AI models. This project is all about discovering candidate problems to work on, from math to science and beyond. We'll explore known problems but also think laterally and creatively to brainstorm problems these kinds of systems may help with that perhaps haven't even been considered yet.

This project is a container for the research we're doing, for the brainstorming we're doing, and for reporting our findings. We'll cast a wide net early for candidate tasks and candidate problems to solve, and we'll dive into more specific aspects of each problem that we have identified or each opportunity that we have identified. 

In developing this project, we will develop agent skills for research. We'll develop dashboards and reporting, and, of course, we'll develop an actual database of sorts of the actual information, ideas, opportunities, and problems that we've identified. 

I haven't decided yet if this is also a repo where we'll actually do some implementations or problem solving. Or perhaps that's better done in separate repositories and then reported back here. That much I don't know yet.
